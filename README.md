# T

A pre-registered strategy-discovery lab for crypto perpetual futures.
- **Goal:** the best net PnL the owner can trade, proven on data the search never saw, and handed over through the
  gates in [`docs/GATES.md`](docs/GATES.md).
- **Scope:** on 2026-11-16 the owner put MEXC, Binance, Gate and KuCoin back in scope, at their own access risk. These
  venues do not serve French residents with perps ([status](docs/STATUS.md)).
- **What counts as an edge:** nothing does until it survives:
  - pre-registration;
  - its family's reality check;
  - an unread sample or forward paper days;
  - costs at 1x, 2x and 3x.

## Use

Reading documents on GitHub needs no environment setup. After following the
[operator setup](docs/guides/OPERATIONS.md#setup-inspection-and-explicit-execution),
these commands inspect existing metadata without starting a research run:

```sh
.venv/bin/python -m lab find funding
.venv/bin/python -m lab find --trace M290
.venv/bin/python -m lab find R400
.venv/bin/python -m lab status --state-dir /absolute/external/paper-runs --strict
.venv/bin/python -m lab integrity
```

- **The operator guide** holds environment installation, the complete test commands, explicit execution,
  paper-account examples and dashboard publication.
- **Before writing:** read [AGENTS.md](AGENTS.md). Run the relevant checks, and the full suite before a code commit.
- **Generated catalogs** come from `scripts/catalog.py`. Stage intended registry and source changes before
  regenerating; `python scripts/catalog.py --check` reports stale views without rewriting them.

## Docs

Read by task, not the whole list.
- **Authorities:**
  - [`docs/STATUS.md`](docs/STATUS.md) for what is true now;
  - [`registry/methods.csv`](registry/methods.csv) for ideas and their state;
  - [`registry/rounds.csv`](registry/rounds.csv) for registered rounds;
  - each lane's PREREG and FINDINGS for its exact scope and result.
- **Marks:** documents marked **live** are kept current. Everything else is dated reference or history. Check its date,
  and check STATUS and the registry, before acting on it.
- **Why files do not move:** frozen PREREGs, pinned inputs and the source intake link to these paths. Moving a file
  would break a frozen link, so `docs/` stays flat and this index groups it instead.

**Where new writing goes**
- What is true now: rewrite [`docs/STATUS.md`](docs/STATUS.md) in place.
- A lane's result: its own FINDINGS.
- A source, a web search, or a reel or video the owner sent: a dated note in [`research/intake/`](research/intake/README.md),
  listed in that folder's guide.
- A dated review or audit: `docs/reviews/<topic>_<yyyymmdd>.md`.
- A how-to: `docs/guides/`.
