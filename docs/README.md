# Repository navigation

Generated by `python scripts/repository_index.py --write` from tracked files in this checkout. The index describes file locations and recorded registry metadata; it does not recompute or promote evidence.

## One place for each decision

| Need | Authority |
|---|---|
| Current operating status | [PANEL](PANEL.md); regenerate with `scripts/panel.py` |
| Objective and evidence gates | [DIRECTION](DIRECTION.md), [GATES](GATES.md), [CRITIQUE](CRITIQUE.md) |
| Current method status and next study | [methods.csv](../registry/methods.csv); [METHODS_QUEUE](METHODS_QUEUE.md) preserves an older snapshot |
| Study verdict and trial count | [rounds.csv](../registry/rounds.csv), then that lane's frozen spec and findings |
| Source scope and aliases | [source intake](../research/intake/README.md) and [methods_aliases.csv](../registry/methods_aliases.csv) |
| Writer claim and review dependencies | [room #7](https://github.com/SaikiK12/T/issues/7), [open PRs](https://github.com/SaikiK12/T/pulls); [ROOM protocol](ROOM.md) |

MAP, EDGE_SCOREBOARD, reviews and old handoffs are interpretations with their own dates. When prose and recorded evidence disagree, inspect the exact lane and report the discrepancy; do not rewrite a frozen specification or silently choose the favorable number.

## Find and maintain

```sh
python scripts/repository_index.py --find funding
python scripts/repository_index.py --find R225 --json
python scripts/repository_index.py --check
python scripts/check_research_integrity.py
python scripts/check_method_intake.py
```

`--find` searches filenames, document headings, recorded experiment metadata, the live methods queue, source aliases and tracked provider catalogs. Those records are searched in place, not copied into this page. It does not search full papers, result payloads or market caches. After adding or renaming tracked files, stage them and run `--write`, then `--check`. Commands below are navigation links, not an execution queue.

## Layout and provenance

- `lab/`: reusable data, accounting, inference and gate primitives.
- `tests/`: offline unit and synthetic checks; test filenames identify the module or lane.
- `templates/lane/`: scaffolding for a new registered study.
- `experiments/<lane>/results/`: result provenance; `journal/`: append-only paper observations.
- Existing paths are retained: frozen specs, source hashes and cross-PR references can depend on them.
- Bulk archives and caches stay outside Git; an index entry does not imply those inputs exist locally.
