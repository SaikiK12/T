## Newly established source mechanics (distinct received scope)

   `F_collateral = q_integer * Q * (C_integer - P_integer)`.

   This helper has no division, rate multiplication, rounding or index lookup. Prefix is already price-weighted by pre-execution (prior R317/R321 scope), so multiplying another index/rate here would double apply a factor. Sign: long q>0 and growing P yield negative F; short q<0 gets positive F. These statements describe the source equation, not authenticated actual cash. There is no explicit canonicalization of a zero sign in this helper; `SignTarget::new_unsafe` receives the product of signs. Conversion/sub/mul implementation and all circuit constraints remain unread.
