receipt clocks and hashes are retained in the plan and capture receipts.

redistributed derivatives, and exclude commercial/live proprietary execution
without a separate agreement. The repository code license does not establish
dataset rights. No Binance sponsorship or endorsement is claimed.

The acquired source files and their derived label/schema findings in this lane
retain that attribution and CC BY-NC-SA4.0 notice. This qualification is purely
personal non-production source research: no financial metrics, return model,
signal distribution, order generation or trading activation. Any production
use needs its own appropriate source-rights determination.
