## Rule or search space
One workflow on the public repository's default branch, standard Ubuntu runner,
scheduled minute17 hourly, also manually dispatchable or triggered by the
owner's exact `/quant-tick` comment on issue7. All triggers share one concurrency
group, never cancel a running writer, and load reviewed default-branch code.
The existing separate Codex research automation is reused and may read/repair
the implementation, but may not start a second live loop on its own host.

Source dispatch **2026-11-07..2026-11-19 00:00 UTC**; R419 separately stops
Nov14. No catch-up for elapsed slots. Seven fixed tasks, arguments, prefixes,
timeouts and state paths in config; every other task remains explicitly blocked
for missing inputs, continuous-host needs, legacy spoofing or unqualified scope.
The owned one-shot subprocess is the only process a timeout may kill. A local
.forward.lock is held before restore and throughout dispatch, matching the
legacy orchestrator. Child entrypoints refuse non-Actions dispatch and every
auxiliary HTTP request checks the campaign window again.

Admission ceiling delegated to R419's unchanged native transport: **1,351 calls,16MiB total,1MiB/response** plus its
unchanged native budgets and source-specific caps. Auxiliary sources share
**512 calls,16MiB total,2MiB/response**. These are small finite forward ceilings,
not renewals of the consumed historical or R401/R402 grants. Reserve response
cap+1 before dispatch; debit exact client-read bytes only when known. Unknown
crash spend retains the reservation. Stored allowed state at most64MiB.

Only declared HTTPS prefixes, public requests, no auth/cookies or browser-UA
spoof. No redirects, paid endpoint, old denied host, alternate geo host or
historical warm download. HTTP401/403/404/429/451 and HTML persist a source stop;
legacy retry/skip handlers cannot swallow the fence's stop. Response bytes are
not rescaled, normalized or replaced. A prepared-hour reservation is committed and pushed to the state branch
BEFORE market requests. The live phase verifies its committed reservation.
An unfinished predecessor blocks a later host; unknown spend is never reset.
FINISHED is published only with the captured counters/state. Interrupted partial
files and cut journals are preserved; malformed journals block restoration.
State publication is a fast-forward Git commit; another writer's unexpected
tip prevents publication. The mutable canonical active_contract selects one
registered immutable workflow; future migrations can retire R420 without
editing its frozen workflow/code.
