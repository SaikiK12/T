# Research sources, designs and reviews

[Repository home](../README.md) · [Complete topic index](../README.md#docs) · [Live methods](../registry/methods.csv)

This folder connects source reading and proposed mechanisms to the existing
methods queue. A source claim or prototype is not a measured new trading edge.

| Area | What to open |
|---|---|
| Received sources and exact read scope | [intake/README.md](intake/README.md): source cards, catalogs, public captures and receipts |
| Equation-discovery engineering | [discovery/README.md](discovery/README.md): bounded grammar, alias checks and synthetic examples |
| Combination reviews | [Main hybrid review](HYBRID_REVIEW_20261029.md), which links the grouped detailed reviews in `reviews/hybrid_20261029/` |
| Prospective implementation handoff | [Dated M090/M322 handoff](PROSPECTIVE_LEADS_DRAFT_20261029.md); check native findings for subsequent work |
| Pinned dataset package | [Unlock-data package](datasets/unlock_market_data_v1/README.md); its declared scope and admission rules remain applicable |
| Public funding captures | `mexc_funding_forecasts/`; source observations and fixtures retain their recorded identities |
| Source-audit tools | Root-level `audit_*.py`, `queue_identifiability.py` and `r221_sequential_null.py`; their paths remain stable for imports and reproduction commands |

Use `python -m lab find TEXT` from the repository root to search document
headings, paths and canonical metadata, including nested reviews. Source intake
entries expose recorded filenames/catalog metadata rather than interpreting the
captured bodies. Results and journals are not searched as documentation.

Add new source facts to the relevant intake bundle and existing method. New
market statistics require a separately registered, frozen protocol; dated
review rankings do not authorize a run or replace current queue status.
