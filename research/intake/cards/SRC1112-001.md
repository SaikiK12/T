## 1. What the source says
- **Exchange rule (data vendor rule).** The free yield endpoints `/pools` and `/chart/{pool}` shut down on
  2026-11-13. The same data stays on the paid API plan at `/yields/v1/...`, with unchanged pool ids. llms.txt
  still lists the free routes. Re-fetched: VERIFIED.
- `/chart/{pool}` returns `{status, data: [{timestamp, tvlUsd, apy, apyBase, apyReward, il7d, apyBase7d,
  pricePerShare}]}`. In the three captured bodies there is one row per UTC date, stamped near 23:01 UTC, and
  `apy == apyBase` in every row.
- **aave-v3 adaptor.** `apyBase = liquidityRate / 1e27 * 100`. Aave accrues supply as simple interest on a
  365-day year between index updates (`calculateLinearInterest`), so the field is an APR. The core Ethereum
  market has `poolMeta` null, which makes `aa70268e-...` the Core-market USDC pool. Re-fetched: VERIFIED.
- **ethena-usde adaptor.** `apyBase` is the latest 8-hour `RewardsReceived` amount x 3 x 365 / TVL, compounded
  weekly. From the code history (not checked against data): the TVL price key changed from USDe to sUSDe on
  2025-04-08, and the method changed on 2024-02-22, 2024-03-15 and 2024-03-18.
- Caveats: the code at 322ddd46 describes today's computation. Whether older rows were recomputed is unknown.
