# Starting a research record

[Repository home](../README.md) · [Working rules](../AGENTS.md)

| Template | Use |
|---|---|
| [lane/PREREG.md](lane/PREREG.md) | Define a new experiment, data boundary, candidates, costs and decision rules |
| [lane/FINDINGS.md](lane/FINDINGS.md) | Report the exact test, verdict, sensitivity and limitations |
| [research_card.md](research_card.md) | Record what was actually received/read from a source and what remains unknown |

Before creating a lane, search the [live methods queue](../registry/methods.csv)
and existing evidence. Claim its identifier and files in
[issue #7](https://github.com/SaikiK12/T/issues/7), register it, and freeze its
protocol and declared inputs before computing market statistics. Copy a
template into a new lane; existing frozen protocols keep their recorded bytes.

Use source cards within the existing [intake](../research/intake/README.md) and
map them to canonical methods rather than maintaining a parallel queue.
